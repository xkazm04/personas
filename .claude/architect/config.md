## Gates
- baseline: `npx tsc --noEmit` | `npm run lint` (record the warning COUNT) | `cargo check` in
  `src-tauri/` | `npm run test -- --run`
- step: the subset the step touched, plus `npm run check:i18n:strict` when locales/strings moved
- final: the full baseline set again, plus `npm run check` (ten gates in an `&&` chain incl.
  `census:check`) before the last commit
- slow: `cargo clippy`, full `cargo test --lib --features desktop` - run in background, read the
  output before the next state-changing action
- Gate calibration: the lint baseline is ~10k warnings. Gate on **no NEW warnings in the files this
  diff touched**, never an absolute count; compare against master for the same files before blaming
  the diff. Same for full-crate clippy.

## Repo law
Authority: `.claude/CLAUDE.md` (parallel-safety primitives apply in full).
- Every user-facing string: key into `src/i18n/locales/en.json` via `useTranslation()`, then
  translated into **all 13 other locales in the same change** - `scripts/i18n/translate-extract.mjs`
  -> fill `.i18n-work/missing-<code>.json` -> `translate-merge.mjs`. The `i18n-no-gaps` pre-commit
  hook blocks gaps. No hardcoded English in JSX, placeholder, title or aria-label.
- Status tokens via `tokenLabel()` from `src/i18n/tokenMaps.ts`; error messages via
  `resolveErrorTranslated()`.
- Semantic design tokens only (`typo-*`, `rounded-*`, `shadow-elevation-*`) - see `.claude/Design.md`
  section 8. Reuse `shared/components` (CATALOG.md); never hand-roll spinners/modals/tooltips/buttons.
- IPC via `invokeWithTimeout`; errors via `toastCatch`/`silentCatch` + the error registry;
  components under 200 LOC.
- New Rust types with ts-rs: run `cargo test export_bindings` and commit `src/lib/bindings/`.
- Doc-sync: user-visible changes update the mapped `docs/features/*` - the Stop hook demands it.
- Commit form: primitive #5 mandates an **isolated-index** commit (`GIT_INDEX_FILE` seeded with
  `git read-tree HEAD`) over your own paths where the rules file says so.

## Lint vehicle
`eslint.config.js` + `eslint-rules/<rule-name>.cjs` (see `enforce-base-modal.cjs` for the shape:
name format, severity, message, optional fix). Register in `eslint.config.js`. Default severity
`warn` - matches the "warnings as known migration" baseline; `error` only on an explicit ship-blocker.

## Test guard vehicle
vitest. Structural tests under `src/__tests__/structural/<pattern>.test.ts`, walking the tree with
`fast-glob` or Node `fs`. Gate: `npm run test -- --run`.

## Smoke

  bridge** (verify a new-code marker first - never trust a stale port).
- Read-only sqlite3 against the live DB (`sqlite3 "file:<path>?mode=ro"`) for state questions.

## Coverage names
For `.personas/memory-outbox.jsonl`, anchor `context` to the **product-level names in
`.claude/codebase-context.md`** (49 names, 8 groups - what the app's DB knows). Do NOT use repo-root
`context-map.json`: it is a peer device's mechanical auto-map with names like `tauri:engine [3/10]`,
none of which the app recognizes, and an unrecognized name is stored with a null context and never
counts toward coverage. As of 2026-08-08 the map (208 contexts), the local app DB (49) and
`.personas/contexts.txt` (773) disagree with a 2-name intersection; the map is export-only, so
`git pull` does not sync a peer's rescan into this machine's DB.
