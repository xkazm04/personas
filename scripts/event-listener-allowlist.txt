# Baseline: registry events that Rust NAMES outside `src-tauri/core/src/events.rs`
# -- i.e. hands to an emitter -- and that no non-test TypeScript references by
# `EventName.X` or by wire literal. Every one of these is a payload the backend
# builds, serialises and pushes across the IPC boundary into nothing.
#
# `scripts/check-event-registry.mjs` (pass 3, run by `npm run check:contracts`)
# fails on any void emit NOT listed here, and ALSO fails when a listed name
# gains a listener or stops being emitted (census convention,
# scripts/census/rules.json) -- a silent drop is what a broken matcher looks
# like, so clearing one costs a deleted line here.
#
# MEASURED at the commit that added this file: 158 registry events, 1,152 .rs
# files and 5,059 .ts/.tsx files walked, 145 events named by Rust outside the
# registry, **35 of them void**. Passes 1 and 2 of the same script were green
# for all 35 the whole time: both registries declare the name, so a name diff
# has nothing to report, and `let _ = app.emit(...)` discards the only runtime
# signal that would have said otherwise.
#
# Five of the 35 had a direct `let _ = app.emit(...)` and a user-visible
# consequence. They were baselined for exactly one commit so the gate landed
# green on measured reality, then WIRED and deleted from this file:
# AUTO_FIX_COMPLETED, ASSERTION_RESULTS and CLIPBOARD_ERROR_DETECTED now reach
# the notification centre / a toast via src/lib/eventBridge.ts;
# CONTEXT_RULE_MATCH settles the ambient-context match list; REVIEW_MESSAGE_ADDED
# makes the manual-review thread live. A sixth name, CLI_VERSION_WARNING, had no
# emitter and no listener and was deleted from both registries instead.
#
# The remaining 30 split into three shapes, named per line below:
#
#   * JOB-STREAM PAIR -- a `*_STATUS`/`*_OUTPUT` pair handed to
#     `BackgroundJobManager::new(...)`. The owning panel awaits the command's
#     return value or polls a snapshot command instead of subscribing, so the
#     progress stream is built and thrown away on every run. Wiring these is a
#     loading-UX change per panel, not a listener; each is its own decision.
#   * NO SURFACE -- the event describes a real condition with no place in the UI
#     to put it. Wiring one means designing a surface, which this gate must not
#     force somebody to invent.
#   * SUPERSEDED -- another transport already carries the same fact.
#
# One bare event CONST name per line. `#` starts a comment.
