# Seeded 2026-09-18 (spark build-process-upgrade, WP6). Three kinds of entry:

#   UNREFERENCED    no reference found anywhere in the repo on 2026-09-18; kept because deleting a
#                   product asset on a grep negative is an operator decision, and converting one
#                   would only ship a second unreferenced file. Delete the file + this line, or
#                   wire it up and convert it.
