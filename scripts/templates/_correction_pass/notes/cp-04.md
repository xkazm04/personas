## 11:34 - PATTERN - Record the correction against the INSTRUMENT, not the item

- What kept seven sentences in one lane from collapsing into a template was asking, each
  time, what the operator's overrule is actually a claim about. It is almost never a claim
  about the item.
- The instrument differed every time: a voice-count threshold, a per source yield tolerance,
  a scoring category, a stopping rule, the belief a hypothesis rests on, the shape of a
  justification. Name that and the sentence cannot be moved to another recipe. Write "the
  rejection is recorded with its reason" and it can be moved to all of them.
- Concrete test that worked: if the correction were filed against the item it was made on,
  what would still be wrong next run. That question produces part 3 for free.

## 11:36 - TRAP - Some recipes must be enriched with a correction that is FORBIDDEN to act now

- conversion-experiment-significance-watch holds that significance is a property of a rule
  fixed before the data was seen. A human overruling its verdict is a claim about the
  stopping rule, not the number, so the ONE thing the next run must not do is apply that
  correction to the experiment in flight. Doing so is exactly the peeking the recipe exists
  to prevent.
- So part 3 is not always "the next run adjusts". Sometimes it is "the correction is dated
  and binds only work that has not started". Anywhere a recipe's authority comes from a
  commitment made in advance (a declared horizon, a pre-registered rubric, a baseline
  frozen before measurement), check for this before writing the obvious sentence. The
  obvious sentence would damage the recipe.

## 11:38 - DECISION - Guidance was the wrong home all seven times

- All seven were 81 to 88 words. In every case the eviction candidate turned out to be
  load bearing and already the reason the recipe is good, so the criterion won every time.
  The brief predicts this and it held completely in a marketing lane.

## 11:39 - NO - Do not expect noes to be spread evenly across lanes

- Sales and marketing A produced 7 yes and 0 no. These recipes rank, propose, score or
  classify by construction; there is no data mover among them. Two of them (promotion
  surfaces, variant hypotheses) are pure proposal recipes where a decline is the only
  signal that ever arrives.
- The closest call was a program digest whose job is visibility rather than selection. It
  still passed, but only on one interpretive call it makes (reading an implausible win rate
  as a question about the stopping rule) rather than on the reporting. If a digest makes no
  interpretive call at all, that is a genuine no.
