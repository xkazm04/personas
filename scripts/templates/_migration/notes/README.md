# Shared notes: the ten migration lanes

One file per lane. **You append only to your own; you read all of them.**

Read every file before your first recipe and again after every fourth or so. Nine other
agents are learning the same craft in parallel, and the point of this directory is that
the second half of your lane is better than the first because of what they found.

Entry format:

```markdown
## HH:MM - TAG - one-line title
- the thing itself, in one to four lines
```

`RESEARCH` a source or finding others can reuse · `PATTERN` a way of writing something
that worked · `TRAP` something that cost you time · `GATE` a gate behaviour worth
knowing · `DECISION` a judgment call others should copy for consistency.

Write an entry when the other nine could use it. Three to eight over a lane is right.
Not a work log: "migrated three recipes" helps nobody.

The contract everything here serves is `../FIELD_GUIDE.md`.
