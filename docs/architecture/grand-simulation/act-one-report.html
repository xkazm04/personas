Against the three goals

What this test exists to prove

These are not a sequence and they do not share a verdict. Each is assessed on its own evidence, and the weakest of the three is the one with the most machinery behind it.

Agents that develop and care for their projects, with the human as counsel

real evidence, half the claim

The Architect designed the bank against BIAN and named regulation, refused three times to create repositories while the doors were missing because half a door would manufacture the orphan class its own design exists to detect, checked its tool surface rather than believing the orchestrator, and caught an arithmetic error that both it and the orchestrator had made. Then it composed the portfolio on its own: six repositories, a declaration in each, four owners, ten goals phrased as acceptance criteria citing standards rather than aspirations.

The half that is not proven: nothing has been developed. The verb in this goal is develop, and no App Master has yet woken, let alone written a line. What today demonstrates is judgement and composition, which is the harder half to fake but not the half that ships a bank.

Hiring AI agents and adopting them into companies

machinery built, never demonstrated

Personas can now ask the hiring product for a role, the hiring product composes a job description from a need and dispatches it back, and a persona that arrives that way is enrolled in the attention loop instead of waiting for a click. The refusals are in place: no automation token means the door is closed rather than open.

Not one hire has run end to end. Every claim in the paragraph above rests on unit tests and a wire contract, not on a role that exists because an agent asked for it. This is the goal with the widest gap between what is built and what is shown.

Orchestrating dozens of projects and agents without an overhaul

defects found and fixed, scale untested

Running the organisation exposed three real scaling defects that reading the code had not. The attention loop served one persona per tick in creation order, so a newer persona starved behind older ones. The active persona cap limited the size of the organisation rather than the load on the machine. Long work was killed by a wall clock that could not tell a slow call from a dead one. All three are fixed, and the ordering fix has a test that fails when the sort is removed.

The largest roster ever actually run here is six personas, five of them enabled, and the session ended with exactly five. Nothing about today is evidence of dozens. What today bought is the removal of three reasons dozens would have failed.

Honest weight

Where the day actually went

Eleven merges landed in the Personas codebase and nineteen commits landed across six bank repositories, of which twelve are scaffolds and declarations. The machine that builds the bank received far more attention than the bank. For Act 0 and Act 1 that is the correct ratio, and it stops being correct the moment Act 3 starts.

Eighteen gaps were measured across the two days and seventeen are closed. Twelve of them were found by running the organisation rather than by reading it, including every one of the three scaling defects above. That is the strongest argument for the simulation as a method: the code review would not have found them, and it had not.

An hour was lost to a machine fault that looked like a broken toolchain. Cargo died with a rustc DLL error on five consecutive builds while the same rustc ran perfectly by hand. The cause was a corrupt cached rustc probe in the target directory, damaged when a dev run was killed mid flight, and a single file deletion fixed it. The launcher now clears that file before every start, so the hour is spent once.

Against the reference

How far this is from the thing it is modelled on

The reference architecture the operator chose carries roughly 74 modules, 217 governance gates each with a self test, and a milestone plan whose first milestone is an audit ready repository with its gates enforced. That first milestone is our Act 3b, and it has not started.

What has transferred so far is the shape rather than the substance: money path as a per service designation, the nineteen row per service contract, the declaration file in every repository, the load rule that a request which did not answer invalidates the percentile. All of it is written down and none of it is yet enforced by anything.
