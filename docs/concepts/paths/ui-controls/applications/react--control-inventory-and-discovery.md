# React application — control inventory & discovery

How this repo publishes its primitive inventory, routes developers and
agents to it, and where the routing has measurably not worked.

## The generated catalog

`src/features/shared/components/CATALOG.md` — **128 reusable components**
(the count is in the header, recounted from the generator's own output on
2026-08-17; the CLAUDE.md line said ~115 until then, a 2026-06-18 figure
that had drifted by 13). Its first three lines state that it is generated by
`scripts/docs/gen-shared-catalog.mjs`, must not be hand-edited, and how to
influence it: a `@catalog <one-line>` JSDoc tag in the component file. The
generator (`gen-shared-catalog.mjs:12-15,93-95`) resolves each entry from,
in order: a `CURATED` override map, the `@catalog` tag, export-adjacent
JSDoc, else blank — and a blank renders as *"(add a `@catalog` tag)"* in the
table, so the nudge to annotate is in the artifact itself. Regeneration is
wired into `predev`/`prebuild` via `npm run gen:catalog`.

Entries are routing aids, not docs: `Button` reads "Never style a raw
<button>", `CopyButton` reads "Use instead of raw navigator.clipboard.writeText",
and the trap primitive is labelled as one — the `CURATED` map entry for
`LoadingSpinner` (`gen-shared-catalog.mjs:57`) reads "RENDERS NOTHING.
Spinners are disabled app-wide…" (corrected 2026-08-13 in `ddeb19cc0` after
the previous entry described it as a spinner, and confused adopters shipped
~75 invisible busy states off that description).

## The de-gating decision, recorded

Commit `ec7eedc4f` (2026-07-22, "de-enforce the shared-component catalog —
reference, not gate") dropped `check:catalog` (staleness) and
`check:catalog-boundary` from the aggregate `npm run check`, downgraded the
shared-tree import-boundary rule in `eslint.config.js:165-200` from `error`
to `warn`, and reframed the CLAUDE.md section from MANDATORY to
recommended. The rationale in the commit body is the technique's soft-gate
trade stated plainly: the catalog stays "the single place to check before
building UI; it just isn't a build gate anymore." Both scripts remain for
manual audits. This is the "either is defensible; what is not defensible is
a hand-edited catalog" clause with the soft option chosen — and chosen
*deliberately, in a commit*, which is what the technique asks for.

## Routing by temptation: the don't-hand-roll table

`.claude/CLAUDE.md` § "Reusing shared components" carries the temptation-
keyed table — left column *a busy state on an action control · "no data"
block · styled `<button>` · `navigator.clipboard.writeText` · `fixed inset-0`
modal backdrop · `title=` / custom tooltip · `.toLocaleString()` for display ·
checkbox styled as switch · `<select>` · custom tab strip · a table + its
skeleton · a lazy-route skeleton · a per-row entrance stagger*; right column
the primitive. It is the artifact every coding session reads before editing,
which is exactly where the technique says the router must live. The full
table plus migration backlog is `docs/refactor/shared-component-reuse.md`;
the curation that pruned 206 → 115 (now 128) is
`docs/refactor/catalog-curation.md`.

## Placement rules, as enforced here

`eslint.config.js:165-200` — `shared/components/**` may not import from
`@/stores`, `@/api`, `@/lib/bindings`, `@/features/<feature>`, or Tauri
runtime APIs; each message names the relocation ("domain → feature,
app-shell → `shared/chrome/`"). App chrome lives in
`src/features/shared/chrome/` (shared, not catalogued). All at warn level
since `ec7eedc4f` — visible, not blocking, per the technique's "advisory
but at least visible" allowance.

## Where routing measurably failed

- **Adoption inversion in the form primitives**: 4 `FormField` adopters vs
  19 shadow wrappers + 120 orphan labels across 49 files (registered at
  `golden-path-deferred-fixes.md#w1-form`). `FormField` is catalogued and
  in the don't-hand-roll table; the shadows still outnumber it ~5:1.
- **Zero-adopter primitive**: `src/hooks/utility/interaction/useRovingTabIndex.ts`
  has no consumer anywhere in `src/` (grep 2026-08-18: the only file that
  mentions it is itself). Registered at `#w10-accessibility` ("a standard
  without adoption"). Note the tab strips implement their own roving
  (`PanelTabBar.tsx:51-69`) rather than calling it — the hook's
  index-keyed signature pushes the identity rule onto consumers, so the
  primitive that exists is the one nobody wants.
- **The `native-title-tooltip` census rule** baselines at 566 files / 1,099
  matches while `<Tooltip>` has 131 adopter files — the routing table's
  `title=` row is the least-followed row in it, and even `CopyButton.tsx:76`
  ships a `title=` fallback.
