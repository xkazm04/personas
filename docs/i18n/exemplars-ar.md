# Gold exemplars — ar (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.execution_failed`

- **en**: Failed to start execution
- **ar**: فشل بدء التنفيذ
- **why**: Textbook AR-VSO event statement — verb فشل leads, exactly matching the technique's own worked example.

## `onboarding.agent_ready_hint`

- **en**: Your agent is ready. Click below to start the first execution and see it in action.
- **ar**: وكيلك جاهز. انقر أدناه لبدء التنفيذ الأول وتشاهده في العمل.
- **why**: Correct nominal existing-state sentence (وكيلك جاهز) followed by a masculine-singular imperative — natural, not calqued, and register-consistent.

## `onboarding.step_discover`

- **en**: Desktop
- **ar**: سطح المكتب
- **why**: Clean two-member iḍāfa where only the final noun carries the definite article — the AR-IDAFA rule applied correctly and unnoticed, which is the goal.

## `onboarding.approve / onboarding.approved`

- **en**: Approve / Approved
- **ar**: سماح / مسموح
- **why**: Masdar-on-control convention plus a consistent الأذن/allow-family word choice that matches this same file's risk_safe_tooltip (السماح) — a good cross-string terminology consistency example.

## `onboarding.tour_complete_title`

- **en**: Tour complete!
- **ar**: اكتملت الجولة!
- **why**: Verb-first completion statement (اكتملت agreeing in gender with الجولة) — idiomatic, matches the same pattern used correctly elsewhere (all_tests_passed, agent_promoted).
