# Gold exemplars — id (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.resume_continue_title`

- **en**: Pick up where you left off
- **id**: Lanjutkan dari posisi terakhir
- **why**: Restructures away from a where-relative-clause instead of calquing di mana — exactly the ID-DIMANA repair strategy done well.

## `onboarding.connect_once_hint`

- **en**: Credentials are shared across your entire agent fleet. Set up a Slack connection once and every agent can use it.
- **id**: Kredensial dibagikan ke seluruh armada agen Anda. Siapkan koneksi Slack sekali dan setiap agen dapat menggunakannya.
- **why**: Natural di- passive for the system fact (dibagikan) plus the correct termbase words (kredensial, armada) in one full sentence.

## `onboarding.promote_hint`

- **en**: Your agent has been verified. Click "Promote" to make it production-ready.
- **id**: Agen Anda telah diverifikasi. Klik \"Promosikan\" untuk membuatnya siap produksi.
- **why**: Correctly escaped literal quotes around a translated UI-element reference, single-word so casing is moot, and idiomatic di- passive (telah diverifikasi).

## `onboarding.questions_waiting_one / questions_waiting_other`

- **en**: {count} question waiting / {count} questions waiting
- **id**: {count} pertanyaan menunggu
- **why**: Correctly collapses both plural-suffixed keys to the same base-form-noun value per ID-CLDR-OTHER instead of inventing an artificial singular/plural distinction.

## `onboarding.what_testing_checks`

- **en**: What testing checks:
- **id**: Apa yang diperiksa pengujian:
- **why**: Idiomatic di- passive with no manufactured agent ("Apa yang diperiksa [oleh] pengujian" avoided) — natural instead of bureaucratic.
