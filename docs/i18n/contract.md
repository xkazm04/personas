# i18n contract — Personas (this repo)

The repo-specific half of the `/i18n-translate` skill (Phase 0 artifact). The
skill's method is portable; everything below is Personas-only fact, verified
against code. If a run proves a line stale, fix it here in the same change.

## Catalog layout

- `src/i18n/locales/<locale>.json`, source of truth **`en.json`** (~16.2k leaf
  keys, 59 top-level sections). 14 languages: `en, zh, ar, hi, ru, id, es, fr,
  bn, ja, vi, de, ko, cs`.
- The runtime does **not** load the files you edit — it loads
  `src/i18n/section-locales/<lang>/<section>.json`, regenerated by
  `node scripts/i18n/split-locales.mjs`. **Editing `locales/*.json` without
  running the splitter ships a no-op.** Commit both.

## Format system — NOT ICU

`interpolate()` in `src/i18n/useTranslation.ts` is one regex:

```ts
template.replace(/\{(\w+)\}/g, (_, key) => vars[key] ?? `{${key}}`)
```

- **`\w` is ASCII-only and the lookup is case-sensitive.** A translated,
  recased, or pluralized placeholder name (`{شخصيةs}`, `{Personas}`) does not
  match and renders **literally on screen**. Placeholder names are frozen,
  byte-identical, in every locale, forever.
- **There is no `{n, plural, …}` syntax.** Do not invent one; it renders raw.

## Plural mechanism — frozen suffixed keys

Plurals are separate keys selected by the call site: `foo_one` / `foo_other` /
`foo_many` / `foo_zero`. The key set is **frozen** — translate each suffixed
key's *value*; never add or remove a category. If a locale genuinely needs a
category the key set lacks, **flag it**, don't fake it.

- In a `_one` value, `count` is always 1. Dropping `{count}` for an idiomatic
  singular (Arabic `خطوة واحدة`) is correct transcreation — but the
  placeholder-parity gate in `translate-merge.mjs` rejects it. Keep `{count}`
  unless you also relax that gate for `_one` keys.

## Fallback — silent, and it bites

A `Proxy` in `src/i18n/useTranslation.ts` deep-merges each locale section over
its English counterpart, so a missing or untranslated leaf silently renders
English. **Key parity proves nothing about translatedness** — in July 2026,
`check:i18n:strict` reported 0 missing across all 13 locales while **41,536
live strings rendered as raw English** (~24% of the app; entire `monitor`,
`twin`, `plugins` surfaces). The `gaps` mode and the untranslated gate exist to
close that hole; run `gaps` before `review`.

## Gates — run ALL before finishing

| Gate | What it catches |
|---|---|
| `npm run check:i18n:strict` | key parity: missing keys, stale/extra keys |
| `npm run check:i18n:untranslated` | values still verbatim English (allowlist: `docs/i18n/untranslated-allowlist.json`) |
| `node scripts/i18n/split-locales.mjs` | regenerates the chunks the runtime loads (post-edit build step) |
| `npm run check:i18n-dead` | keys no source file references — don't translate these (2,671 as of 2026-07; `debt` and `planner` were 100% dead) |

## Do-not-translate seeds

Brand names (Personas, Claude, GitHub, GitLab, Slack, Sentry, Obsidian,
Discord, Notion, YouTube), technical identifiers (API, CLI, JSON, HTTPS, cron,
webhook, SQLite, MCP, P2P, ONNX), enum/token codes, CSS classes, URLs, code
identifiers, user-generated content.

- **Trap:** "Personas" the product ≠ "personas" the plural common noun. In
  `common.all_personas` = "All personas" the word is a noun and **must** be
  translated. Judge by the call site, not the spelling.
- **`_comment*` key segments are translator notes** — never rendered, never
  translated, copied verbatim (`translate-extract.mjs` splits them out).

## Call-site lookup

Grep `t.<section>.<key>` across `src/` (property-access idiom, not a `t("…")`
call).

## Operational notes

- **Parallel safety** — a full run rewrites 13 large files. Per
  `.claude/CLAUDE.md`, work in a `git worktree`, stage only your own paths,
  never `git stash`.
- ~90 keys per batch is the ceiling that has worked here.
- Register: Personas is a professional developer tool → formal address (Czech
  *vykání*, German *Sie*, French *vous*, Japanese *です・ます*, Korean
  *합쇼체/해요체*). Per-locale detail in `style-<locale>.md`.
- Glossary seed domain: persona, agent, capability, connector, credential,
  vault, recipe, template, trigger, execution, run, schedule, deployment,
  healing, observability, fleet, orchestration, draft, promote.
- The `i18n-no-gaps` pre-commit hook runs `check:i18n:strict`; adding
  `check:i18n:untranslated` there is the open wiring gap.
