# Gold exemplars — hi (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.tour_complete_recap`

- **en**: You finished all {total} steps.
- **hi**: आपने सभी {total} चरण पूरे कर लिए।
- **why**: Correct ergative agreement: the perfective compound पूरे कर लिए agrees with the masculine-plural object चरण, not with the आप subject — exactly the HI-AGREE ergative rule, done right with a countable placeholder in a safe (proper-noun-like, non-declining) slot.

## `onboarding.execute_description`

- **en**: Execute {name} and see real-time output.
- **hi**: {name} निष्पादित करें और रीयल-टाइम आउटपुट देखें।
- **why**: Clean verb-final honorific imperatives (निष्पादित करें, देखें) with the {name} placeholder moved to the front subject-like slot per Hindi word order — HI-SOV and HI-IMPER both textbook.

## `onboarding.desktop_description`

- **en**: We found these apps on your machine. Allow access so your agents can interact with them directly.
- **hi**: हमें आपकी मशीन पर ये ऐप मिले। अपने एजेंट को उनके साथ सीधे इंटरैक्ट करने की अनुमति दें।
- **why**: Idiomatic light-verb construction (अनुमति दें rather than a calqued 'allow'), correct danda, and a light-verb-compound interact (इंटरैक्ट करने) handled the settled way.

## `onboarding.tour_handoff_body`

- **en**: Your first agent is live. Take a quick guided tour of the rest — connections and running agents — and we'll skip the parts you just did.
- **hi**: आपका पहला एजेंट लाइव है। बाकी का एक त्वरित निर्देशित टूर लें — कनेक्शन और एजेंट चलाना — और हम उन हिस्सों को छोड़ देंगे जो आपने अभी किए।
- **why**: Multi-clause sentence with verb-final order held throughout, native-vs-transliterated dial correct (लाइव, टूर stay borrowed; छोड़ देंगे, किए native), and 'connections' correctly transliterated here (कनेक्शन) unlike the Latin-stranded instances flagged above.
