# Gold exemplars — ja (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.desktop_empty_hint`

- **en**: You can connect desktop apps later from the Connections section.
- **ja**: デスクトップアプリは後で「接続」セクションから接続できます。
- **why**: Pronoun-free, kagi-quotes the referenced UI section name per JA-KAGI-QUOTES, and uses the direct potential できます instead of the ~することができます anglicism.

## `onboarding.tour_complete_recap`

- **en**: You finished all {total} steps.
- **ja**: 全 {total} ステップを完了しました。
- **why**: Pronoun dropped, correct completed-action ました per JA-TENSE-ASPECT, placeholder in natural position with counter-noun ステップ.

## `onboarding.execute_description`

- **en**: Execute {name} and see real-time output.
- **ja**: {name}を実行してリアルタイム出力を確認します。
- **why**: Placeholder moved to where the を particle wants it per JA-PARTICLE-PLACEHOLDER, full です・ます sentence for body text.

## `onboarding.connect_once_hint`

- **en**: Credentials are shared across your entire agent fleet. Set up a Slack connection once and every agent can use it.
- **ja**: 認証情報はエージェントフリート全体で共有されます。Slack接続を一度設定すれば、すべてのエージェントが使用できます。
- **why**: Correct termbase terms (認証情報, フリート), pronoun dropped, direct potential できます, register consistent.

## `onboarding.tour_step_of`

- **en**: Step {current} of {total}
- **ja**: {total}ステップ中{current}番目
- **why**: Both placeholders relocated to satisfy Japanese particle structure (中/番目) while keeping names byte-identical — clean label-class example of JA-PARTICLE-PLACEHOLDER.
