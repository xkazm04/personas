# Gold exemplars — cs (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.execution_failed`

- **en**: Failed to start execution
- **cs**: Spuštění se nepodařilo zahájit
- **why**: Reflexive-passive recast instead of an agentless English-style passive — CS-ACTIVE done right, error-message class.

## `onboarding.desktop_scan_error_hint`

- **en**: We couldn't reach the discovery service. Check your network and try again, or skip this step.
- **cs**: Nepodařilo se spojit se službou pro rozpoznávání aplikací. Zkontrolujte připojení k síti a zkuste to znovu, nebo tento krok přeskočte.
- **why**: Clean formal-imperative body copy, no inserted 'Vy', correct verb-per-clause chaining — instruction/hint class.

## `onboarding.questions_waiting_other`

- **en**: {count} questions waiting
- **cs**: {count} otázek čeká
- **why**: Correct genitive-plural 'other' workaround for the missing cs 'few' slot, plus correct singular-verb agreement with a quantified genitive-plural subject — count-string class.

## `onboarding.connect_once`

- **en**: Connect once, use across all agents
- **cs**: Připoj jednou, použij napříč všemi agenty
- **why**: Short, idiomatic tykání imperative pair, no article/pronoun bloat — heading/CTA class.

## `onboarding.execution_completed`

- **en**: Execution completed successfully
- **cs**: Spuštění úspěšně dokončeno
- **why**: The short passive participle here is correct, not a CS-PASS violation, because it grammatically agrees with the neuter noun 'spuštění' rather than standing in for an omitted long form — status-message class.
