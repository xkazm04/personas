# Gold exemplars — vi (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.run_agent`

- **en**: Run Agent
- **vi**: Chạy tác nhân
- **why**: Bare imperative, no pronoun, correct native verb chạy — textbook VI-IMPERATIVE button label.

## `onboarding.agent_promoted`

- **en**: Agent promoted!
- **vi**: Tác nhân đã được thăng cấp!
- **why**: được used correctly for a favorable resultative (VI-PASSIVE) — the promotion is good news, marked as such.

## `onboarding.desktop_scan_error`

- **en**: Could not scan your desktop.
- **vi**: Không thể quét máy tính của bạn.
- **why**: Concise status sentence, single của bạn, no calqued subject padding — clean VI-PRONOUN-CALQUE discipline.

## `onboarding.test_check_creds`

- **en**: Credentials are valid and have correct permissions
- **vi**: Thông tin xác thực hợp lệ và có quyền chính xác
- **why**: Adjective predicates with no là (VI-COPULA: hợp lệ predicates directly), and the long-established credential rendering held consistently.

## `onboarding.conn_desktop`

- **en**: Desktop Bridge
- **vi**: Cầu nối máy tính
- **why**: Head-first compound (VI-WORDORDER) with a natural bridge metaphor, sentence-cased, no Title Case mirroring.
