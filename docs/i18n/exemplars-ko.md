# Gold exemplars — ko (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.because_you_connected`

- **en**: Because you connected {apps}, these templates fit best:
- **ko**: {apps}을(를) 연결하셨으므로 다음 템플릿이 가장 잘 맞습니다:
- **why**: Dual particle on the placeholder, the user-action honorific -셨- used correctly (never on system actions), and the English two-clause 'because...' fused into one -으므로 connective clause instead of a calque.

## `onboarding.execute_description`

- **en**: Execute {name} and see real-time output.
- **ko**: {name}을(를) 실행하고 실시간 출력을 확인하세요.
- **why**: Placeholder moved to the natural verb-final position with the correct dual particle, clean 해요체 imperative.

## `onboarding.questions_waiting_one / questions_waiting_other`

- **en**: {count} question(s) waiting
- **ko**: 질문 {count}개 대기 중
- **why**: Both plural branches correctly collapse to the identical Korean form (CLDR ko has only 'other') instead of inventing a fake distinction.

## `onboarding.tour_target_offscreen`

- **en**: What this step points at isn't on screen yet — it'll highlight once it appears.
- **ko**: 이 단계가 가리키는 대상이 아직 화면에 없습니다 — 나타나면 강조됩니다.
- **why**: Natural condition clause (-면) instead of a translated 'once/when' calque, correct 합쇼체 register, no stray pronouns.

## `onboarding.more_connectors`

- **en**: +{count} more
- **ko**: 외 {count}개
- **why**: Tight, idiomatic badge compression with the counter glued directly to the numeral — good example of length discipline in fixed-width chrome.
