# Gold exemplars — zh (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.questions_waiting_other`

- **en**: {count} questions waiting
- **zh**: {count} 个问题等待回答
- **why**: Correctly words the _one/_other pair identically per ZH-PLURAL-OTHER — questions_waiting_one carries the exact same Chinese text, differing only by the substituted {count}.

## `onboarding.answers_help_hint`

- **en**: Your answers help the AI choose the right connectors, triggers, and policies.
- **zh**: 您的答案帮助 AI 选择正确的连接器、触发器和策略。
- **why**: Clean ZH-ENUM: 、 joins the sibling list items, 和 only before the last — no stray ，-as-comma-splice, no 的-chain.

## `onboarding.local_tooling_sentence`

- **en**: Personas has local tooling connected from the start — Messaging, Database, Vector, and more — no credential required.
- **zh**: Personas 从一开始就内置了本地工具——消息、数据库、向量等——无需凭据。
- **why**: Model instance of the doubled, unspaced dash —— as a parenthetical (contrast with the six spaced-single-dash defects found elsewhere in this same batch), correct 、-enumeration, and correct termbase word for credential (凭据).

## `onboarding.dim_triggers_desc`

- **en**: How and when it activates
- **zh**: 激活方式和时间
- **why**: Recasts an English 'how and when' clause into a tight Chinese noun phrase instead of translating word-for-word — no translationese connective scaffolding.

## `onboarding.tour_explore_to_continue`

- **en**: Take your time. Click below when you've explored this section.
- **zh**: 请慢慢浏览。了解完这部分内容后，点击下方按钮继续。
- **why**: 请 correctly marks a consequential imperative sentence (not a button label), and the string never over-inserts 您 — good instance of the register technique's pronoun economy.
