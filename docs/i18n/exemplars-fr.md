# Gold exemplars — fr (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.getting_started`

- **en**: Getting Started
- **fr**: Premiers pas
- **why**: Idiomatic French heading, not a literal calque — good short label exemplar.

## `onboarding.resume_continue_title`

- **en**: Pick up where you left off
- **fr**: Reprenez là où vous vous étiez arrêté
- **why**: Natural French sentence rhythm, no trace of the English idiom’s structure — good prose exemplar.

## `onboarding.answer_questions_hint`

- **en**: Answer them in the matrix to shape your agent’s design.
- **fr**: Répondez-y dans la matrice pour façonner la conception de votre agent.
- **why**: Correct dative pronoun "y" instead of a calqued "les répondre" — good pronoun-use exemplar.

## `onboarding.because_you_connected`

- **en**: Because you connected {apps}, these templates fit best:
- **fr**: Comme vous avez connecté {apps}, ces modèles sont les mieux adaptés :
- **why**: Correct vous-register, correct non-breaking space before the colon, placeholder kept intact — good placeholder-bearing sentence exemplar.

## `onboarding.connector_count_stat`

- **en**: 200+ Built-in Connectors
- **fr**: Plus de 200 connecteurs intégrés
- **why**: Recast the glued "200+" into idiomatic French rather than gluing "+" onto a number — good stat-label exemplar.
