# Gold exemplars — ru (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.tour_progress_done`

- **en**: {completed} of {total} done
- **ru**: Выполнено {completed} из {total}
- **why**: RU-FROZEN handled correctly: a verb-based rephrase ("Выполнено") sidesteps count-agreement entirely instead of freezing a declined noun.

## `onboarding.agent_promoted`

- **en**: Agent promoted!
- **ru**: Агент продвинут!
- **why**: Correct perfective passive participle agreeing in gender with «агент» (masculine) — clean RU-PARTICIPLE application.

## `onboarding.conn_api_key`

- **en**: API Key / Token
- **ru**: API-ключ / токен
- **why**: Textbook RU-COMPOUND: Latin do-not-translate term as attributive, hyphen, Russian head noun carrying the grammar.

## `onboarding.tour_complete_recap`

- **en**: You finished all {total} steps.
- **ru**: Вы прошли все шаги: {total}.
- **why**: De-anglicization rephrase that moves the noun out of the number's government ("все шаги" stays nominative plural, unaffected by {total}'s value) — avoids the RU-FROZEN trap other count strings in this file fell into.
