# Gold exemplars — de (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.tour_progress_done`

- **en**: {completed} of {total} done
- **de**: {completed} von {total} erledigt
- **why**: Placeholder pair reordered naturally into German syntax with names untouched — exactly the placeholder-in-case-neutral-position discipline the format contract wants.

## `onboarding.desktop_scan_error_hint`

- **en**: We couldn't reach the discovery service. Check your network and try again, or skip this step.
- **de**: Der Suchdienst war nicht erreichbar. Prüfen Sie Ihre Netzwerkverbindung und versuchen Sie es erneut, oder überspringen Sie diesen Schritt.
- **why**: Clean recast (not a literal 'we couldn't reach' calque), correct Sie throughout, no register drift despite being an error/retry surface.

## `onboarding.narration_mute`

- **en**: Mute narration
- **de**: Erzählung stummschalten
- **why**: Short button label; 'Erzählung' stays the one word for narration across all three sibling keys (replay/mute/unmute) — DE-ONE-WORD done right.

## `onboarding.risk_safe_tooltip`

- **en**: Read-only access, safe to allow
- **de**: Nur-Lese-Zugriff, sicher zu erlauben
- **why**: Correct Durchkopplung on a borrowed-English-flavored compound ('Nur-Lese-Zugriff') instead of a bare-space or half-coupled form.

## `onboarding.coach_substep_promote`

- **en**: Promote
- **de**: Veröffentlichen
- **why**: The one place in this batch that gets the promote termbase row right, standing in contrast to the drift found in promote_hint/run_test_hint/agent_promoted.
