# Gold exemplars — bn (personas)

Register by demonstration: the locale's best reviewed pairs, one per string class where possible.
Seeded 2026-08-24 from the onboarding review wave (registry localization bundle anchors). Grow toward ~8 pairs;
replace a pair only when a better one ships.

## `onboarding.tour_show_me_title`

- **en**: Scroll to and re-highlight this on screen
- **bn**: এই উপাদানে স্ক্রোল করে আবার হাইলাইট করুন
- **why**: Correctly chains two actions with the conjunctive participle -এ করে instead of the miscoordination seen in subtitle — the model this catalog should follow for compound imperatives.

## `onboarding.tour_locate_title`

- **en**: Show me where this is
- **bn**: এটি কোথায় আছে দেখান
- **why**: আছে used correctly as a genuine locative assertion (BN-ZEROCOP's exception), not as a copula filler.

## `onboarding.test_check_creds`

- **en**: Credentials are valid and have correct permissions
- **bn**: ক্রেডেনশিয়াল বৈধ ও সঠিক অনুমতি আছে
- **why**: Cleanly combines zero-copula (বৈধ, no verb for the equational half) with আছে for the genuinely possessive half — exactly the discipline BN-ZEROCOP asks for.

## `onboarding.desktop_scan_error`

- **en**: Could not scan your desktop.
- **bn**: আপনার ডেস্কটপ স্ক্যান করা যায়নি।
- **why**: Idiomatic passive-of-availability (করা যায়নি) instead of a calqued English passive — the error-copy engine BN-LIGHTVERB names.

## `onboarding.tour_complete_recap`

- **en**: You finished all {total} steps.
- **bn**: আপনি সব {total}টি ধাপ সম্পন্ন করেছেন।
- **why**: Classifier correctly glued to the placeholder ({total}টি) — the counter-example that exposes tour_intro_steps' missing classifier in the same catalog.
