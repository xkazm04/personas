# Cohorts

## Philosophy
A portfolio of 102 projects holds only a handful of distinct PASSPORTS, so draw
each shape once and let it state how many projects it speaks for.

## How it stays readable at scale
It is the only one of the four that gets easier as the portfolio grows: more
projects do not make more bands, they make the existing bands speak for more.
The cost is the number of distinct shapes - on this machine 14 of 102 projects
have a scan at all, so most passports are identical. That buys the room for
full-size marks, a dimension-name rail written once at full type size, and a
short page. The grouping is an exact signature over every cell of the lens, so
two projects share a band only when every dimension agrees: a fact about the
data, never a judgement about it.

## The wow moment
The headline the figure computes about itself - "6 shapes · 102 projects" - and
the `41 of 102` on each band. The practical turn follows from it: you do not
fix a project here, you fix a SHAPE, and the band tells you how many projects
that one fix reaches. Only the band holding the cursor opens, so the members
appear as a level rather than as another layer of the same page.

## Known limits
A fully scanned portfolio would have few shared signatures and degrade toward
one band per project - it is strongest exactly where the data is sparse, which
is today and may not be next year. A band's marks address the roving project
when open and the band's first member when closed, which is one rule to learn.
