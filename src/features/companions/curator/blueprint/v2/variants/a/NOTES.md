# The Signature

## The one idea

Nine columns become **one 114px mark per row**: nine 10px slots, position is identity, and
the ruler above the list carries the nine channel numbers on the same grid, so a slot
resolves to a reason by reading up rather than by hovering.

The four facts differ by **orientation, not hue**:

| fact | mark |
|---|---|
| scored | a bar from the floor; height is one of five bands against the plan's largest cell |
| measured zero | a flat tick **on** the floor |
| unknown | a dotted vertical stem, **off** the floor |
| unmeasurable | a diagonal slash |

The two measurements share a baseline; the two non-measurements float off it, so the pairs
read as pairs before either is named. It survives colour-blindness, both themes, greyscale.
A subject that scores nothing is a flat dashed line. A total that is only a floor carries
the same dotted stem beside its figure.

## How the two columns divide

The same `ListRow` at 48px on both sides — state Mark on the spine, one name on the reading
line, mark and figure at the same right edge, both strips the same height — so the eye reads
one surface. Only what the mark counts differs: nine reasons left, two extracted facts right.

## What a queued intake looks like before enrichment

Host and path, quiet rather than bold; the skill tinted beside it; the operator's own note;
and **two dotted stems** — topic unknown, impact unknown. A bare-runnable skill (`harvest`,
`librarian`) shows two slashes: no resource to read. Nothing is blank or a shimmer.

## Known limits

Cell-level `unmeasurable` has no producer in `buildModel` yet; `planFixture.ts` derives it
from `applications: 0`. `useLanes` carries the push subscription, but the request-level
event does not exist. Bands, not a ramp: cells 3 points apart can draw alike.
